隔离 `JEA_HOME` + 可选已构建 `JEA.app` / dir-only 包：`npm run release:recovery-matrix`。Linux CI 用 `--bounded`，不要求 `JEA.app`。

| 项 | 状态 | 证据 |
| --- | --- | --- |
| 五个退化夹具：all-stopped / mixed-domain / dead-pid-zombie / externally-attached / reactor-backlog-stalled | implemented | `scripts/release-recovery-fixtures.mjs`；复用 `readSubjectReadiness` |
| 打包树嵌入 build provenance，不向上发现 checkout | implemented | dir fixture + `JEA_PROJECT_ROOT`；macOS 可对 `JEA.app` 再跑 |

| External-attach：App 退出后外部 daemon 仍存活 | implemented | 产品不杀 attached PID |
| 三次 launch → recover → quit：无孤儿进程、自有端口、锁或假 stale/zombie | implemented | 有界路径清理 worker-state / lock；有 Web bundle 时再跑 start/stop |
