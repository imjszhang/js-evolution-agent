# Bundled UI fonts

These WOFF2 files are loaded by the shared renderer so Electron, the Web
preview, and Playwright screenshots use the same glyphs.

| File | Family | License |
| --- | --- | --- |
| `inter-latin-400.woff2` / `inter-latin-600.woff2` | Inter | SIL OFL 1.1 (`OFL-Inter.txt`) |
| `noto-sans-sc-subset.woff2` | Noto Sans SC (shell CJK subset) | SIL OFL 1.1 (`OFL-NotoSansSC.txt`) |

Do not rely on system UI fonts for visual baselines.
